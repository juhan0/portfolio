**1. 프로그램과 프로세스**
- 프로그램 파일과 실행 중인 프로세스의 차이
프로그램은 특정 목적을 수행하기 위한 명령문들의 집합. 컴퓨터에 저장 되어있는 실행 가능한 파일.
프로세스는 프로그램이 실행되고 있는 상태.

- 같은 프로그램을 여러 번 실행하면 어떻게 되는가?
하나의 프로그램에서 여러 개의 프로세스가 만들어진다. 각 프로세스는 독립적인 실행 상태와 메모리 공간을 가진다.

- 프로그램 파일을 삭제해도 프로세스가 바로 종료되지 않는 이유 고찰하기
실행중인 프로세스는 실행될 때 프로그램 파일이 메모리에 저장되어 CPU가 그 메모리를 사용하여 실행한 것이기 때문에 파일을 삭제해도 이미 메모리에 올라와 있는 내용으로 프로세스가 바로 종료되지 않는다.

**2. Linux 경로와 파일**

- 리눅스에서  /, ., .., ~,의 의미

          / 루트 디렉터리, 리눅스 파일 시스템의 가장 최상위 폴더

          . 현재 디렉터리, 현재 위치한 폴더

          .. 부모 디렉터리, 현재 폴더의 한단계 위 폴더

          ~ 홈 디렉터리, 현재 사용자의 개인 홈 폴더

- 절대경로와 상대경로의 차이

파일이나 폴더의 위치를 찾아가는 두가지 방식.
상대경로는 현재 위치한 디렉터리를 기준으로 파일이나 폴더의 위치를 나타내는 방법. 절대경로는 /를 기준으로 파일 위치를 나타내는 방법

- pwd, ls, file, stat, mkdir, rmdir,, cp, rm이 각각 무엇을 확인하는 명령인지 알아보기

          Pwd: (print working directory) 현재 위치하고 있는 경로를 출력하는 명령어

          ls: (list) 현재 디렉터리에 있는 파일과 폴더를 확인

          file: 파일의 종류를 확인

          stat: 파일이나 디렉터리의 자세한 정보를 확인

          mkdir: 새로운 디렉터리 생성

          rmdir: 비어있는 디렉터리를 삭제

          cp: 파일이나 디렉터리를 복사

          rm: 파일이나 디렉터리를 삭제

- 와일드카드란?

파일명과 일치하는 패턴으로 특정 파일을 찾을 때 사용한다. ls cp mv 등 다른    명령어와 조합해서 사용한다. 와일드카드 문자로는 * ? [] {} 등이 있다.

ex)

test?.txt      임의의 한 문자에 대응

`*.txt`          0개이상의 문자열에 대응

test[12].txt = test1.txt test2.txt 대괄호 안의 문자 중에서 하나와 일치하는 문자에 대응

test[!1].txt = test1.txt를 제외한 test?.txt   test12.txt는 []부분에 한글자만 있지 않아서 X

test[1-3].txt = test1.txt test2.txt test3.txt   []의 범위는 한문자 단위

t{est,ast}.txt = test.txt tast.txt 중괄호 안에 쉼표로 구분한 여러 문자열 중에서 하나에 대응

test{001..100}.txt = test001.txt 부터 test100.txt    {}의 ..범위는 여러 값 생성

  **3. Linux 권한**

- 사용자·그룹·그 외 사용자의 의미
리눅스는 파일과 폴더의 접근 권한을 사용자User 그룹Group 그 외 사용자Other       로 나눈다. 사용자는 해당 파일의 소유자, 그룹은 해당 파일이 속한 그룹의 사용  자, 그 외 사용자는 사용자와 그룹에 속하지 않는 나머지 사용자.

- r, w, x의 의미

r 읽기 4 / 파일의 내용을 읽을 수 있는 권한

w 쓰기 2 / 파일의 내용을 수정할 수 있는 권한

x 실행 1 / 파일을 프로그램처럼 실행할 수 있는 권한

ex) rwxr-xr-x   ->   3자리씩 끊어서.

rwx 7 (사용자가 접근할 수 있는 권한) 읽기쓰기실행 모두 허용

r-x 5 (그룹에 속한 사용자들 접근 권한) 읽기실행 허용

r-x 5 (모든 사용자가 접근할 수 있는 권한) 읽기실행 허용

- 일반 파일과 디렉터리에서 x 권한의 차이

일반 파일에서는 x가 실행할 수 있는 권한.

디렉터리에서 x는 실행보다는 그 디렉터리 안에 접근하거나 들어갈 수 있는 권한

디렉터리에서 r 목록 확인/  w 파일, 디렉터리 생성, 삭제/  x 접근, 탐색

`-` 표시는 일반 파일 / d 표시는 디렉터리

- chmod 600, chmod 755 해석

파일이나 디렉터리의 권한을 변경하는 명령어

600 -> rw- --- --- 사용자는 읽기 쓰기 가능 그룹과 그 외 사용자는 아무 권한 없음

755 -> rwx r-x r-x 사용자는 읽기쓰기실행 가능 그룹과 그 외 사용자는 읽기 실행 가능

  **4. Git의 역할**

- Git과 일반 파일 백업의 차이

일반파일백업은 파일을 수정할 때마다 모두 복사하여 저장하는 방법. 용량을 많이 차지하고 무엇이 어떻게 바뀌었는지 추적이 어렵다.

Git은 파일 전체를 계속 복사하지 않고 변경된 이력을 버전 단위로 저장. 누가 언제 어떻게 코드를 수정했는지 기록되어서 효율적이다.

- 작업 디렉터리, staging area, commit의 관계

작업 디렉터리 -git add->  staging area  -git commit->  repository

작업 디렉터리는 현재 내가 작업하고 있는 파일들이 있는 곳

Staging area는 수정한 내용을 일시적으로 저장하는 영역. 작업 디렉터리에서 파일을 수정하고 git add 명령어를 사용하여 변경 사항을 staging area에 추가.

Commit은 staging area에 있는 파일들의 변경 사항들을 버전으로 기록하는 단계

Git commit 명령어를 통해 저장소에 저장.

- git status, git diff, git log가 각각 답해주는 질문

Git status는 현재 어떤 파일이 변경됐고 staging area에 올라갔는지 확인(현재 git상태)

Git diff는 아직 staging하지 않은 변경 내용 확인(수정된 내용)

Git log는 commit의 기록과 과거 버전의 이력 확인(과거에 어떤 commit을 했는지)
