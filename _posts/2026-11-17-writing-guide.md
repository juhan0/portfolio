> 이 글은 블로그 사용 안내입니다. 실제 공부 기록이나 프로젝트 성과를 대신 작성한 글이 아닙니다.

## 새 글 만들기

1. [새 글 작성 화면](https://github.com/juhan0/portfolio/new/main/_posts)을 엽니다. GitHub 로그인이 필요합니다.
2. 파일 이름을 **YYYY-MM-DD-영문제목.md** 형식으로 입력합니다. 
3. 아래 기본 양식을 복사하고 제목, 날짜, 주제와 본문을 바꿉니다.
4. 오른쪽 위 **Commit changes…**를 누른 뒤 **Commit changes**로 저장합니다.
5. 배포가 완료되면 공부 기록 목록에 자동으로 표시됩니다. 목록을 따로 수정할 필요가 없습니다.

파일 이름 예: `2026-11-17-first-note.md`

## 글의 기본 양식

~~~~markdown

description: "이 글을 한 문장으로 소개합니다."

## 오늘의 주제
공부한 주제와 목표를 적습니다.

## 핵심 개념
내 말로 이해한 내용을 정리합니다.

## 실습과 시행착오
시도한 방법, 오류 메시지, 해결 과정을 적습니다.

## 남은 질문
아직 헷갈리는 점과 다음에 확인할 내용을 적습니다.

## 참고 자료
- [자료 제목](https://example.com)
~~~~

날짜는 실제 작성일로 바꾸세요. 미래 날짜의 글은 그 날짜가 오기 전에는 목록에 표시되지 않습니다. 주제와 태그는 원하는 이름으로 자유롭게 추가할 수 있습니다.

## 코드와 표 넣기

코드 앞뒤를 백틱 세 개로 감싸고 언어 이름을 붙이면 코드 블록이 됩니다.

~~~~markdown
```python
print("공부 기록 예시")
```
~~~~

실제 표시 예시:

~~~python
print("공부 기록 예시")
~~~

| 항목 | 적을 내용 |
| --- | --- |
| 원인 | 문제가 생긴 이유 |
| 시도 | 직접 해 본 방법 |
| 결과 | 해결 여부와 배운 점 |

## 이미지 넣기

이미지를 저장소의 `assets/img/posts/` 폴더에 올리고 아래처럼 연결합니다.

~~~~markdown
![실습 결과 설명](/portfolio/assets/img/posts/example.png)
~~~~

파일 이름의 대소문자와 확장자를 맞추세요. 설명에는 이미지가 무엇을 보여주는지 적으면 좋습니다.

## 짧은 메모도 괜찮습니다

완성된 긴 글일 필요는 없습니다. 오늘 이해한 개념 한 줄, 막혔던 오류, 다시 볼 링크만 적어도 됩니다. 제목 아래의 날짜·주제·태그, 오른쪽 목차, 전체 기록 링크는 자동으로 만들어집니다.

공개 저장소에 저장한 글과 이미지는 다른 사람도 볼 수 있습니다. 비공개 메모용 공간은 아닙니다.
