## 01. 희망 직무 선정

### 1. 보안 직무의 4가지 카테고리

| 구분 | 주요 역할 | 대표 직무 |
| --- | --- | --- |
| 공격 | 취약점을 발견하고 공격 가능성을 검증 | 모의해킹, 취약점 연구 |
| 방어 | 공격을 탐지하고 사고를 분석·대응 | 보안관제, 침해사고 대응 |
| 관리 | 보안 정책과 조직의 위험을 관리 | 보안 감사, GRC |
| 제작 | 보안 시스템을 구축·설정·개선 | 인프라 보안, 네트워크 보안, 클라우드 보안 |

### 2. 인프라 보안 엔지니어

**인프라 보안 엔지니어(Infrastructure Security Engineer)**는 기업의 서버, 운영체제, 네트워크, 클라우드 등 IT 인프라를 안전하게 구축하고 운영하는 직무이다.

주요 업무는 다음과 같다.

- Linux·Windows 서버의 보안 설정 관리
- 사용자 계정 및 접근 권한 관리
- 방화벽, VPN 등 네트워크 보안 시스템 운영
- 시스템 취약점 점검 및 개선
- 서버·네트워크 장애 원인 분석
- 보안 로그 확인 및 이상 징후 대응
- 시스템 구성과 보안 점검 결과 문서화

인프라 보안은 제작과 방어 분야가 결합된 직무이며, 새로운 보안 소프트웨어를 개발하기보다 기존 시스템을 구성하고 보호하는 업무도 포함한다.

## 03. 채용공고 공통 요구 역량

### 1. 공통 역량 정리

| 역량 | 필요한 이유 |
| --- | --- |
| 운영체제·Linux | 서버의 구조와 상태 이해 및 설정 관리 |
| 네트워크 | 서버 간 통신과 접근 제어 이해 |
| 정보보안 기초 | 위험한 설정과 취약점 식별 |
| 방화벽·VPN | 네트워크 보안 환경 구성·운영 |
| 문제 해결 | 장애와 보안 문제의 원인 분석 |
| 문서화·협업 | 변경 이력과 분석 결과 전달 |
| 클라우드 | 클라우드 및 하이브리드 인프라 보호 |
| Python·Shell | 스크립트 작성과 기술적 작업 지원 |

### 2. 공통적으로 요구되는 핵심 역량

**① 운영체제 이해**

Linux 서버를 관리하기 위해 파일 시스템, 프로세스, 사용자 계정, 파일 권한 등의 개념을 이해해야 한다.

**② 네트워크 이해**

서버와 네트워크 장비를 보호하기 위해 IP, 포트, TCP/IP, 라우팅, 방화벽의 작동 원리를 알아야 한다.

**③ 보안 설정 및 접근통제**

불필요한 접근을 제한하고 사용자에게 적절한 권한을 부여하는 능력이 필요하다.

**④ 문제 분석 및 해결**

시스템에 오류가 발생했을 때 로그와 설정을 확인하고 원인을 분석하여 해결할 수 있어야 한다.

**⑤ 문서 작성 및 협업**

보안 설정을 변경한 이유와 결과를 기록하고, 다른 담당자에게 정확하게 전달하는 능력이 필요하다.

조사한 기업들은 공통적으로 운영체제와 네트워크에 대한 기본 지식을 요구하였다.

특히 방화벽·VPN 등 보안 시스템을 이해하고, 문제가 발생했을 때 원인을 분석하여 해결하는 능력을 중요하게 평가하였다.

따라서 인프라 보안 엔지니어가 되기 위해서는 **Linux, 네트워크, 보안 기초, 문제 해결 능력**을 우선적으로 갖추어야 한다.

## 04. Career Path

### Linux 및 운영체제 기초 학습

**학습 목표:** Linux 시스템의 기본 구조를 이해하고 직접 조작할 수 있는 능력 갖추기

학습 내용:

- Linux 파일·디렉터리 구조
- 사용자·그룹·파일 권한
- 프로세스와 서비스
- SSH 원격 접속
- 시스템 로그 확인
- 기본적인 Shell 명령어

### 네트워크 기초 학습

**학습 목표:** 네트워크의 작동 원리를 이해하고 연결 문제를 분석하기

학습 내용:

- IP 주소와 서브넷
- TCP/UDP와 포트
- DNS, HTTP, HTTPS
- 라우팅과 스위칭
- 방화벽과 VPN

### 시스템 보안 기초 학습

**학습 목표:** 위험한 시스템 설정을 식별하고 개선하기

학습 내용:

- 인증과 인가
- 최소 권한 원칙
- 서버 보안 강화(Hardening)
- 취약점과 보안 설정 오류
- 보안 로그의 기본 분석 방법

### 인프라·클라우드 기초 학습

**학습 목표:** 실제 기업에서 사용하는 인프라 환경 이해하기

학습 내용:

- 서버 가상화
- Linux 서버 운영
- 네트워크 구성
- AWS EC2·VPC·Security Group·IAM
- 서버 백업과 복구의 기본 원리
